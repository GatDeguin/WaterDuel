# Taller del Cauce - v3

Propuestas 34, 36 y 37: detalles de construccion, sello original y motivos funcionales.

Los siete GLB conservan el BIN v2 completo, sus accesores originales, ejes, escala y sockets.
Solo se anexan capas de microincrustacion proyectadas; no hay cortes booleanos, desplazamiento,
colliders nuevos ni integracion automatica con el juego. Los materiales y texturas PBR son los de v2.

La fuente Blender contiene los originales importados y detalles nuevos con nombres V3_ separados;
activar una coleccion V3_Editable_* para editar una pieza en su origen de agarre.

Ejecutar el autor con Blender background y luego node scripts/validate-equipment-craft-v3.mjs.
Los renders se realizan reimportando los GLB finales en una escena limpia.
